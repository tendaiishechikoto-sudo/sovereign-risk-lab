# Manual data — Phase Two (African Football Transfer Economy)

Every row in every CSV here carries a `source_url` and `date_retrieved`, validated by `scripts/ingest_manual.py` — an unsourced row is rejected, not silently accepted (same rule as phase one's `raw/manual/`).

- `cies_expatriate_totals.csv` — 2020–2025 aggregate expatriate counts and global rank for the five African nations with verified figures in CIES Football Observatory Monthly Report 100 (Nigeria, Ghana, Senegal, Côte d'Ivoire, Cameroon). This is the sole input to the Football Export Footprint Index (FEFI) — see `/methodology.md` in the project.
- `cies_nigeria_trend.csv` — year-by-year 2020–2025 expatriate counts for Nigeria only. The report gives this level of detail for Nigeria and a handful of major exporters (Brazil, France, Argentina, England, Spain, Germany, Colombia) but not for Ghana, Senegal, Côte d'Ivoire, or Cameroon — confirmed by direct source review, not assumed. Kept separate from the index (single-year figures are used there) and presented as a case-study trend.
- `cies_nigeria_destinations.csv` — Nigeria's top five destination countries 2020–2025, the only destination-level breakdown for an African nation in this report. Notably, none of the five are "Big 5" European leagues — which is exactly why a "destination concentration in Big-5 leagues" index component was dropped rather than approximated from this one country's partial data (see `notes` column and `/methodology.md`).
- `case_study_transfers.csv` — named individual players currently abroad for Zimbabwe, Kenya, and Malawi, since none of the three appear in CIES's aggregate tracking at all. Illustrative only — not a sample large enough to generalize from, and stated as such in the README/frontend. Only one row (Collins Sichenje) has a confirmed transfer fee; every other cell left blank rather than estimated.
- `value_capture_context.csv` — the real figures found on agent commissions and the FIFA solidarity mechanism, kept explicitly narrative (not fed into any computed index): current confederation-level agent-fee totals (2025) and a historical (2018–2019) solidarity-mechanism compliance figure. Each row's `caveat` column states exactly why it isn't trustworthy as a scored metric — see `/methodology.md` "Source verification findings" for the full reasoning.

If you refresh this project later, re-verify every row — CIES publishes a new Monthly Report roughly monthly and FIFA's Agents/Transfer reports refresh annually; none of these figures should be assumed current beyond the `date_retrieved` shown.
